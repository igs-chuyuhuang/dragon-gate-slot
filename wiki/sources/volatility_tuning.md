## 一、問題診斷

### 玩家反饋
> 「錢變少太快，缺乏輸贏起伏」

### 根因分析

**目前基礎 RTP 僅 68.18%**（遠低於設計目標 96.4%）

| 指標 | 目前數值 | 業界標準 | 問題 |
|------|---------|---------|------|
| 基礎 RTP | 68.2% | 92~96% | ❌ 嚴重偏低 |
| 單轉贏率 | 28.2% | 30~40% | ⚠️ 偏低 |
| 10 轉正收益機率 | 9.1% | 35~45% | ❌ 極低 |
| 100 轉獲利機率 | 0.0% | 25~35% | ❌ 不可能贏 |
| 平均連輸 | 3.6 轉 | 2.5~3.0 | ⚠️ 偏長 |

### 為什麼 RTP 這麼低？

目前機制的數學問題：

1. **每轉先扣全額 bet（30）**，然後只有穿門才能回本
2. **碰壁只回 +1.2×betPerRow = 12**（已扣 30，淨虧 18）
3. **穿門機率低**：13 張牌中，穿門需要 mid 落在 lo~hi 之間，機率有限
4. **same-hit 額外扣 3×bet = 90**：雪上加霜
5. **miss/same-miss 完全不退**：佔比最高的結果卻是全額損失

逐項機率分析（每列）：
- 穿門：~20.1%（回報 1~6 倍 betPerRow）
- 碰壁：~15.4%（回報 1.2 倍 betPerRow，但已扣 betPerRow）
- same-hit：~0.59%（額外扣 3×bet）
- miss + same-miss：~63.9%（全額損失 betPerRow）

**結論：63.9% 的結果是全額損失，碰壁也是淨虧損，只有 20% 的穿門能回本。這不是「波動性」問題，是 RTP 設計缺陷。**

## 三、推薦方案：F

### 方案 F 設計

| 結果類型 | 目前 | 方案 F | 變化 |
|---------|------|--------|------|
| 穿門（極窄 gap≤1） | +6× betPerRow | **+8×** betPerRow | 大贏更大 |
| 穿門（窄 gap≤3） | +4× betPerRow | **+5×** betPerRow | 提升 |
| 穿門（中 gap≤7） | +2× betPerRow | **+2.5×** betPerRow | 微升 |
| 穿門（寬 gap>7） | +1× betPerRow | **+1.2×** betPerRow | 微升 |
| 碰壁 | +1.2× betPerRow | **+1.8×** betPerRow | 差一點也有獎 |
| 同值命中 (same-hit) | **-3× bet** | **0**（不額外扣） | 移除懲罰 |
| 未穿 (miss) | 0 | 0 | 不變 |

### 設計理念

1. **碰壁變正面體驗**：+1.8× betPerRow = 回收 18（已扣 10），淨賺 8。「差一點穿過去」不再是懲罰，而是小獎。
2. **穿門大贏更大**：極窄門 8× 讓幸運穿門有「爽感」。
3. **移除 same-hit 懲罰**：原本 -3×bet（-90）太殘酷，改為「已扣的 betPerRow 就是代價」。
4. **保持機台利潤**：RTP 96.25%，機台邊際 3.75%。

### 體感改善對比

| 指標 | 目前 | 方案 F | 改善幅度 |
|------|------|--------|---------|
| 10 轉正收益機率 | 9.1% | **42.2%** | +364% |
| 100 轉獲利機率 | 0.0% | **32.5%** | 從不可能→三成機會 |
| 單轉贏率 | 28.2% | **35.8%** | +27% |
| 平均連輸 | 3.6 | **2.8** | -22% |
| 平均連贏 | 1.4 | **1.6** | +14% |

### 玩家體驗預期

- 🎰 每 10 轉有 42% 機率是正收益（目前只有 9%）
- 💰 100 轉後有 32.5% 機率賺錢（目前 0%）
- 🔥 碰壁不再是「又輸了」，而是「差一點，但還是有小獎！」
- 🐉 極窄門穿過去 8× 回報，有「贏了一波」的爽感
- ⚖️ 機台仍有 3.75% 邊際利潤

## 五、實作建議

### 需修改的檔案

1. **`web/js/payoutCalculator.js`**
```javascript
export function calculate(judgments, bet) {
  const betPerRow = bet / 3;
  let total = 0;
  for (const j of judgments) {
    if (j.type === 'through') total += betPerRow * j.mult;
    else if (j.type === 'wall') total += betPerRow * 1.8;  // 原 1.2 → 1.8
    // same-hit: 不額外扣（移除原本的 -bet*3）
  }
  return total;
}
```

## 六、結論

| 問題 | 原因 | 解法 |
|------|------|------|
| 錢減少太快 | 基礎 RTP 僅 68%，63.9% 結果全額損失 | 提高穿門賠率 + 碰壁改正面 |
| 缺乏起伏 | 贏率太低(28%)，10轉正收益僅9% | 方案 F 提升至 35.8% 贏率、42% 正收益 |

| same-hit 太殘酷 | -3×bet 一次扣 90 | 移除額外懲罰 |

**🏆 推薦採用方案 F**：碰壁 +1.8×、穿門 8/5/2.5/1.2×、same-hit 不額外扣。RTP 96.25%，體感大幅改善。
