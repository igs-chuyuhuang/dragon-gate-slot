# V1 Scope — 射龍門 Slot 最小可玩版

> 截止日：2026/05/28（週四）｜目標：能跑就好，可用 placeholder 素材

## ✅ V1 包含功能（In-Scope）

### 1. 基本 Spin 流程
- 按下 Spin 按鈕 → 轉軸轉動 → 停止顯示結果

### 2. 盤面出牌
- 3×3 盤面，每格隨機出牌
- 牌值範圍：A（1）~ K（13）+ Scatter（龍符號）
- Scatter 每格出現率 5%（V1 出現但不觸發 Free Game）

### 3. 穿門判定（每列獨立判定）

| 情境 | 判定 | 賠率 |
|------|------|------|
| 左 ≠ 右，中欄落在區間內 | 穿門 | 依門寬（1×~6×） |
| 中欄 = 左或右界值 | 碰壁 | 1.2× |
| 中欄超出範圍 | 未穿 | 0 |
| 左 = 右，中欄 = 同值 | 同值命中 | −3×（扣款） |
| 左 = 右，中欄 ≠ 同值 | 判輸 | 0 |

### 4. 穿門賠率表

| 門寬等級 | 左右差距 | 賠率 |
|---------|---------|------|
| 極窄門 | 差 1 點 | 6× |
| 窄門 | 差 2~3 點 | 4× |
| 中門 | 差 4~7 點 | 2× |
| 寬門 | 差 8~11 點 | 1× |

### 5. 派彩計算與餘額更新
- 三列結果加總計算總派彩
- 同值命中扣款（需預檢餘額 ≥ 3× 押注）
- 即時更新玩家餘額

### 6. 基本 UI
- 餘額顯示
- 下注金額選擇 / 按鈕
- Spin 按鈕
- 盤面結果顯示（3×3 牌面）
- 每列判定結果提示（穿門/碰壁/未穿/同值命中）
- 本輪贏分顯示

## ❌ V1 不包含功能（Out-of-Scope → V2）

| 功能 | 延後原因 |
|------|---------|
| Free Game（Scatter ×3 觸發） | 需完整 JP 系統配合 |
| JP 彩金系統（Basic/Major/Grand） | 依賴 Free Game 流程 |
| 正式美術素材 | V1 用 placeholder |
| 音效 | V2 整合 |
| 動畫特效（轉軸、穿門、派彩） | V2 整合 |
| JP 貢獻累積（每注 5%） | 隨 JP 系統一起做 |

## 🎯 驗收標準

1. **完整流程**：玩家能完成「設定下注 → 按 Spin → 看盤面結果 → 判定穿門 → 派彩更新餘額」一輪完整循環
2. **判定正確**：三列各自獨立判定，穿門/碰壁/未穿/同值命中邏輯正確
3. **賠率正確**：依門寬賠率表計算，碰壁 1.2×，同值命中 −3×
4. **餘額保護**：餘額不足 3× 押注時，禁止下注（防同值命中爆倉）
5. **可重複遊玩**：派彩後可繼續下一輪 Spin

## 📋 技術備註

- Unity 2D 專案
- Placeholder 素材：純色方塊 + 文字標示牌值即可
- 不需要伺服器，單機運行
- 隨機數用 Unity 內建 Random 即可（V1 不需 server-side RNG）
