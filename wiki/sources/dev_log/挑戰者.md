# 挑戰者 (Challenger) 開發紀錄

### [2026-05-29] — 射龍門玩法大改提案挑戰辯論

**環節：** 設計決策 / 魔鬼代言人
**AI 工具：** Kiro Agent
**做了什麼：** 針對 liaohuanjie 的玩法大改提案（Main Game 改傳統轉輪 + Bonus 改射龍門），對企劃（反對方）和創意總監（支持方）進行兩輪質疑辯論，逼出雙方盲點並收斂立場。

**挑戰要點：**
- 對企劃：質疑「時程不夠」缺乏工時評估、「辨識度」在 Slot 市場價值為零、折衷方案的數學可行性（追加期望值、查表感）
- 對創意總監：質疑 Slot 玩家是否需要決策感、複雜度爆炸（3 級追加+連擊+分級龍門）、控制幻覺破滅的反噬、追加無下行風險=假決策
- 共同質疑：目標玩家定位模糊、損失厭惡心理學、法規合規風險

**辯論成果：**
- 企劃立場修正：從「情緒性反對」→「時程約束下的務實判斷 + 6/23 後 A/B test + 預設評估標準」
- 創意總監立場修正：從「瘋狂疊加功能」→ 收斂為兩個核心支柱（門寬可見 + 有限預算池）+ 極簡決策 + 懲罰與追加解耦
- 識別 5 個待驗證問題：預算池 RTP 模擬、工時評估、評估標準文件、法規合規、快速模式 UX

**Before：** 團隊對提案的討論停留在直覺和情緒層面，支持/反對理由模糊
**After：** 雙方立場收斂為可驗證的具體命題，下一步是跑數據（工時、RTP、法規）而非繼續爭論方向
**耗時：** ~5 分鐘（兩輪質疑 + 總結）

### [2026-06-09] — 射龍門完整規則邏輯檢查

**環節：** 設計決策 / 品質把關
**AI 工具：** Kiro Agent
**做了什麼：** 對射龍門整套遊戲規則（Main Game / Free Game / Bonus Game / JP 系統）進行全面邏輯檢查，找出矛盾、漏洞、玩家體驗風險。

**發現問題：**

邏輯矛盾（3 項）：
- Scatter 燈扣罰邊界條件未定義（能否扣到負數？）
- 「三格同值」既是 JP 觸發條件又是撞柱懲罰 — 直接衝突
- Bonus passRate 固定 15% 但顯示不同門寬 — 語義不清

玩家體驗風險（4 項）：
- Bonus 85% 碰壁率 → 37% 玩家前半段連續 6 次失敗 → Bonus 像懲罰不像獎勵
- Scatter 倒扣 = 西西弗斯推石頭反模式，激怒耐心有限的玩家
- JP 只在極窄/窄門觸發，玩家可能玩 1000 轉不知道 JP 存在
- Bonus 規則寫「同值撞柱 -3×」但又「避免 gap=0」→ 死規則

數學漏洞（3 項）：
- Bonus「碰壁 -2×」基數未定義（bet or 當前籌碼？）直接影響 RTP
- Main Game 各門寬出現機率未定義，無法計算 RTP
- Scatter 5% 含義歧義（每轉 vs 每格），差 10 倍

UI/UX 問題（3 項）：
- Bonus 門寬視覺 vs 實際 15% passRate = 視覺欺騙
- 同轉獲得 Scatter + 碰壁的動畫順序未定義
- FG/BG 選擇缺乏資訊提示 = 盲猜

**最嚴重問題：** 「三格同值 = JP 還是撞柱」的矛盾 + Bonus 門寬視覺欺騙
**Before：** 規則表面看起來完整
**After：** 識別出 13 個需要解決的問題，其中 2 個會直接損害玩家信任
**耗時：** ~3 分鐘
