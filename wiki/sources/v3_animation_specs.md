# V3 動畫時間軸與美術需求規格

> 創意總監 🐉 ｜ 2026.06.04
> 針對必做三項 + 瞇牌緊張感 + 龍珠條 UI 的實作細節

## 一、瞇牌緊張感（每轉核心節奏改造）

### 設計目標
還原射龍門「瞇牌」的核心緊張感：左右先停看到門寬 → 中軸牌背遮蓋 → 揭牌瞬間。

### 時間軸（每轉 ~2.2 秒）

| 時間 | 事件 | 動畫/音效 |
|------|------|-----------|
| 0.0s | Spin 啟動 | 三軸同時轉動，spin_release 音效 |
| 0.8s | 左軸停定 | thud 音效，牌面正常顯示 |
| 1.0s | 右軸停定 | thud 音效，**門框動畫撐開**顯示門寬等級 + 賠率文字 |
| 1.0~1.3s | 靜音過渡 | BGM 淡出，只剩中軸低頻轉動聲 |
| 1.3s | 中軸減速 | 牌面切換為「牌背」（金色龍紋背面） |
| 1.8s | 中軸停定 | 牌背靜止，完全靜音 0.2 秒 |
| 2.0s | 揭牌 | 牌背從中間裂開翻轉，單次鼓點「咚」 |
| 2.2s | 結果演出 | 穿門/碰壁/未穿對應特效 |

### 特殊觸發：極窄門加強版（門寬差 2 點，×4 以上）
- 揭牌前多 0.5 秒：牌背微微掀起一角 → 蓋回（假動作）
- 配合倒吸氣音效
- 總時長延長至 ~2.7 秒

### 美術資源需求

| 資源 | 規格 | 數量 |
|------|------|------|
| 牌背圖 | 金色龍紋，與正面同尺寸 | 1 張 |
| 牌背翻轉動畫 | 6 幀 spritesheet 或 CSS 3D flip | 1 組 |
| 門框撐開動畫 | 左右門柱向外擴張 | 3 級（窄/中/寬） |
| 門寬賠率文字 | 燙金字體，顯示 "×1" "×2" "×4" "×6" | 4 種 |

### 音效需求

| 音效 | 描述 | 時長 |
|------|------|------|
| gate_reveal | 門框撐開的木頭/金屬聲 | 0.3s |
| silence_tension | 靜音 + 微弱心跳 | 0.5s |
| card_flip | 牌背裂開翻轉 | 0.3s |
| drum_hit | 揭牌瞬間鼓點 | 0.2s |
| gasp_tease | 極窄門假動作倒吸氣 | 0.4s |

## 二、龍息連擊（#1 Dragon Breath Combo）

### 時間軸

連擊在穿門結果演出後觸發（不影響基本節奏）：

| 連擊數 | 追加演出時長 | 動畫描述 |
|--------|-------------|---------|
| 2 連擊 | +0.5s | 小龍頭從右下角探出 + 火苗，計數器「×1.2」閃現 |
| 3 連擊 | +0.8s | 龍身延伸到畫面 1/3，螢幕邊緣金色火焰，計數器「×1.5」 |
| 5+ 連擊 | +1.2s | 龍身環繞全屏，火焰粒子爆發，計數器「×2.0」+ 震動 |
| 連擊斷裂 | +0.5s | 龍嘶吼 → 散成金色粒子消散 |

### 程式邏輯

```
comboCount = 0
每轉結果：
  if 穿門成功:
    comboCount++
    multiplier = comboCount >= 5 ? 2.0 : comboCount >= 3 ? 1.5 : comboCount >= 2 ? 1.2 : 1.0
    payout *= multiplier
    播放對應連擊動畫
  else:
    if comboCount >= 2: 播放斷裂動畫
    comboCount = 0
```

### 美術資源需求

| 資源 | 規格 | 數量 |
|------|------|------|
| 龍身 sprite | 3 段長度（短/中/長），帶火焰粒子 | 3 組 |
| 連擊計數器 | 燙金數字 ×1.2 / ×1.5 / ×2.0 | 3 種 |
| 螢幕邊緣火焰 | loop 動畫，金色 | 1 組 |
| 龍散消散 | 粒子消散動畫 | 1 組 |

### 音效需求

| 音效 | 描述 |
|------|------|
| combo_2 | 低沉龍吟 + 火焰音 |
| combo_3 | 中等龍吟 + 打擊音（音高上升） |
| combo_5 | 完整龍嘯 + 爆裂音 |
| combo_break | 龍嘶吼 + 風散音 |

## 三、龍門加速（#9 Turbo Gate Rush）

### 觸發條件
Free Game 最後 3 轉自動觸發。

### 時間軸

| 時間 | 事件 |
|------|------|
| 觸發瞬間 | 畫面閃白 0.2s → 背景切換為金色衝刺隧道 |
| 每轉節奏 | 原本 2.2s → 壓縮到 1.0s（取消牌背揭牌，直接快速停軸） |
| 轉間間隔 | 原本等玩家按 → 自動 0.3s 間隔連續 spin |
| BGM | 切換為加速版（BPM ×2）+ 心跳底鼓 |
| 最後一轉 | 慢動作：中軸停定用 1.5s（製造最終懸念） |
| 結束 | 背景恢復 + 累積分數定格放大 + 過渡到 JP 判定 |

### 美術資源需求

| 資源 | 規格 | 數量 |
|------|------|------|
| 衝刺隧道背景 | 金色速度線 loop 動畫 | 1 張/組 |
| 閃白過渡 | 全屏白色 fade | 1 |
| 速度線 overlay | 兩側斜線粒子 | 1 組 |

### 音效需求

| 音效 | 描述 |
|------|------|
| turbo_start | 加速引擎啟動音 + 鼓點 |
| turbo_bgm | 加速版 BGM loop（約 4 秒） |
| turbo_final | 最後一轉慢動作 — 低頻拉伸 + 心跳 |

## 四、大龍門開啟儀式（#10 Grand Gate Ceremony）

### 觸發條件
Free Game 8 轉結束後，進入 JP 判定階段。

### 時間軸（總長 ~6 秒）

| 時間 | 事件 | 動畫 |
|------|------|------|
| 0.0s | 畫面暗下 | 全屏 fade to black 80%，只剩累積分數發光 |
| 0.5s | 分數上移居中 | 數字飛到畫面中央放大 |
| 1.0s | 三道龍門升起 | 從下方依序升起：銅門(Basic) → 銀門(Major) → 金門(Grand) |
| 2.0s | 光柱啟動 | 分數化為光柱從底部上升，速度先快後慢 |
| 2.5~4.0s | 光柱上升 | 經過每道門時該門發光提示，製造「會不會停在這？」的懸念 |
| 4.0s | 光柱停定 | 停在對應 JP 門的位置 |
| 4.2s | 命中演出 | 門框爆開 + 金幣雨 + JP 名稱全屏 |
| 5.5s | 獎金顯示 | 跳數動畫顯示獲得金額 |
| 6.0s | 結束 | fade 回主遊戲 |

### 未達門檻（分數 < 60）
- 光柱只升到 1/4 高度 → 熄滅
- 安慰文字「保底獎勵」+ 小額金幣落下
- 總時長縮短為 ~3 秒

### 美術資源需求

| 資源 | 規格 | 數量 |
|------|------|------|
| 三道龍門 | 銅/銀/金三色，帶中國風門框裝飾 | 3 張 |
| 光柱動畫 | 垂直上升，金色粒子拖尾 | 1 組 |
| 門框爆開特效 | 3 級華麗度（銅/銀/金） | 3 組 |
| 金幣雨粒子 | 全屏落下 | 1 組 |
| JP 名稱文字 | "BASIC JP" / "MAJOR JP" / "GRAND JP" 燙金 | 3 種 |

### 音效需求

| 音效 | 描述 |
|------|------|
| ceremony_dark | 畫面暗下環境音 |
| pillar_rise | 光柱上升 — 音高隨高度升高 |
| gate_pass | 光柱經過門時的「叮」提示 |
| gate_explode_bronze | 銅門命中爆炸 |
| gate_explode_silver | 銀門命中爆炸（更華麗） |
| gate_explode_gold | 金門命中爆炸（最華麗 + 號角） |
| coin_rain | 金幣落下叮噹聲 |
| consolation | 未達門檻安慰音 |

## 五、龍珠條 UI（碰壁扣燈進度系統）

### 位置
轉軸正上方門楣橫樑區域（viewport 390×844 中約 x:40~280, y:180~200）。

### 規格

| 項目 | 規格 |
|------|------|
| 珠子數量 | 5~7 顆（依設計決定扣燈門檻） |
| 珠子大小 | 20~24px 直徑（手機版） |
| 亮燈狀態 | 金色內發光 + 微粒子環繞 |
| 滅燈狀態 | 暗灰凹陷，無發光 |
| 容器 | 嵌入金色雕花橫樑裝飾帶 |

### 動畫

| 事件 | 動畫 | 時長 |
|------|------|------|
| 點亮（穿門成功） | 珠子從暗灰 → 金色脈衝 + 「叮」音 | 0.3s |
| 熄滅（碰壁扣燈） | 珠子碎裂 → 碎片掉落消散 + 碎裂音 | 0.5s |
| 全滿觸發 | 所有珠子同時爆發光芒 → 觸發獎勵 | 1.0s |

### 美術資源需求

| 資源 | 規格 | 數量 |
|------|------|------|
| 龍珠 (亮) | 金色球體，帶內光 | 1 張 |
| 龍珠 (暗) | 灰色凹陷球體 | 1 張 |
| 橫樑底座 | 金色雕花裝飾帶，寬度同轉軸 | 1 張 |
| 碎裂動畫 | 珠子碎成 5~6 片 spritesheet | 1 組 |
| 點亮脈衝 | 金色光暈擴散 | 1 組 |

### 音效需求

| 音效 | 描述 |
|------|------|
| pearl_light | 珠子點亮叮聲（音高隨數量遞增） |
| pearl_break | 碎裂音 |
| pearl_full | 全滿爆發 — 和弦 + 龍吟 |

## 六、開發優先級與排程建議

### Phase 1（V2 收尾，~6/11 前）
1. **瞇牌節奏改造** — 改停軸順序 + 加牌背揭牌（影響每轉體驗，最優先）
2. **龍息連擊** — 計數器 + 乘數邏輯 + 基礎動畫

### Phase 2（V3 Demo 衝刺，6/11~6/20）
3. **大龍門開啟儀式** — Demo 王牌演出
4. **龍門加速** — FG 最後 3 轉節奏變化
5. **龍珠條 UI** — 碰壁扣燈視覺系統

### 美術總需求清單

|------|------|

| 動畫/Spritesheet | ~12 組 |
