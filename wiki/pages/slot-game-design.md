# Slot 遊戲機制設計

## Main Game 射龍門

3×3 盤面，每列獨立判定。每局扣 bet（分配到 3 列）。

| 判定 | 條件 | 結果 |
|------|------|------|
| 穿門 | 中間在左右之間 | +bet/3×mult + 歸還bet/3 |
| 碰壁 | 中間=左或右 | 扣bet/3, scatter-1 |
| 同值碰壁 | 左=右=中 | 扣bet/3, scatter-2 |
| 未中 | 中間在門外 | 扣bet/3 |
| 同值穿 | 左=右, 中≠左 | +bet/3×1 + 歸還 |

倍率：極窄×10 / 窄×5 / 普通×2 / 寬×1

## Scatter 收集系統

- 每格 5% 機率出現 scatter 龍珠 (+1)
- 碰壁: -1，同值碰壁: -2
- 收集滿 10 → 選擇 FG 或 BG
- 設計考量：碰壁扣燈增加不確定性，同值重罰增加戲劇性

## Free Game (FG)

- 8 轉免費（不扣 bet）
- 中輪帶獎勵符號：[bet×0.2, ×0.33, ×0.5, ×1.0, ×1.5, 空]
- 穿門時獎勵飛到累積欄
- FG MISS_BIAS = 30%（比 MG 高，控制報酬）
- 期望報酬 ≈ 1.65×bet

## Bonus Game (BG)

- 12 局射龍門牌局
- 初始籌碼/保底 = bet×2
- 穿門×1 / 碰壁-2× / 同值碰壁-3× / 未中-1×
- 中間牌純隨機 1-13
- All in 輸: winnings = guarantee, chips = 0, BG 結束
- 12 局結束: cashOut = max(winnings, guarantee)
- 設計：穩定回收選項（vs FG 高波動）

## Jackpot 系統

- 觸發：3 列全為窄門（gap≤3）
- Symbol pool 15 個，依 bet 動態調整內容
- 三格獨立抽，三同中獎
- bet<300 無 GRAND
- 獎金依池累積發放
- 視覺：左右停→中輪閃爍→JP 符號跟著滾→停輪顯示結果

## 多人競賽模式

- 輸入姓名+組別（SF/HP/QS/其他）→ 開始倒數
- 時間到/餘額不足 → 自動提交分數
- BIG WIN / FG/BG 選擇期間暫停倒計時
- 等當局（FG 8轉/BG 12局）完整結束才結算
- 排行榜：個人排名 + 組別平均分排名
- Google Apps Script + Sheets 後端

## 機制平衡

- MG 高頻低獎（維持節奏）
- FG 中頻中獎（免費轉爽感）
- BG 中頻穩定（保底兜底）
- JP 極低頻大獎（驚喜感）
- 競賽模式讓波動率產生策略性（auto vs 手動 bet 調整）
