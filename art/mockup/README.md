## 共用核心設計（兩版相同）

- **3×3 盤面**：翡翠玉石底板 + 金色如意紋邊框 + 翡翠珠交叉點
- **龍門牌坊外框**：綠色琉璃瓦飛簷 + 紅色匾額「射龍門」+ 金色龍柱
- **Symbol 風格**：翡翠底 + 金色浮雕文字（文字由程式疊加）
- **Scatter 龍**：紅底金龍圓形
- **SPIN 按鈕**：大型紅玉圓形 + 金色外圈
- **底部操作列**：中國紅底色 + 金色邊框 + 金色文字
- **小龍吉祥物**：Q版翡翠小龍持金元寶，左下角
- **色彩體系**：翡翠綠 + 中國紅 + 金色
- **背景基調**：荷花池仙境 + 黃昏暖光天空

| 元素 | 手機版 (9:16) | 網頁版 (16:9) |
