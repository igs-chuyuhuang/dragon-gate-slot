## 工作方式

v2 改為「設計控制 + AI 素材輔助」：
1. AI（Pollinations.ai）只生成獨立美術元素
2. Python PIL 控制精確 layout 和文字渲染
3. 合成腳本：`compose_v2.py`（可重複執行）

## 共用核心設計（兩版相同）

- 3×3 盤面：翡翠玉石底板 + 金色邊框 + 翡翠珠交叉點
- Symbol 風格：翡翠底 + 金色浮雕文字（PIL 渲染）
- 色彩體系：翡翠綠 + 中國紅 + 金色
- 紅色底部操作列 + 金色上邊框
- 紅玉 SPIN 按鈕 + 金色外圈
- 深綠金邊資訊面板
- Q版小龍吉祥物
- 紅色宮燈裝飾
- 所有 UI 文字由 PIL 精確渲染（非 AI 生成）
