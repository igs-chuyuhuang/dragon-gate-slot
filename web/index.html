🐉 射龍門 Slot — 遊戲規則

【畫面說明】

  • 標題下方三個圖示為 JP 彩金池：🔵 Basic / 🟠 Major / 🔴 Grand
  • 數字為目前累積獎金
  • 押注區：點擊金額按鈕直接切換押注
  • Auto：先選次數（10/50/100），再按 Auto 開始自動轉

【基本玩法】

  • 3×3 盤面，每列獨立判定
  • 左欄和右欄決定「門寬」
  • 中欄決定是否「穿門」
  • 中欄落在左右之間 = 穿門成功
  • 中欄等於左或右邊界 = 碰壁
  • 中欄超出範圍 = 未穿

【賠率表】

  • 極窄門（差1點）：×6
  • 窄門（差2~3點）：×4
  • 中門（差4~7點）：×2
  • 寬門（差8~11點）：×1
  • 碰壁：×1.2
  • 同值命中（左=右=中）：扣 3 倍押注

【下注說明】

  • 每注分配給 3 列，每列 bet/3
  • 最低餘額要求：3 × 押注金額

【Scatter 龍符號】

  • 每格 5% 機率出現
  • 同一轉出現 3 個以上觸發 Free Game
  • Scatter 所在列不參與主遊戲判定

【Free Game】

  • 觸發後獲得 8 轉免費遊戲
  • 計分規則：穿門 +中欄牌值、碰壁 +中欄牌值×3
  • FG 中再出 3 個 Scatter 可延伸 +8 轉（最多 2 次）
  • FG 結束後用累積分數判定 JP

【JP 彩金系統】

  • Basic JP：累積 60~120 分（中心 90）
  • Major JP：累積 130~200 分（中心 165）
  • Grand JP：累積 210~320 分（中心 265）
  • 精準命中中心值：獎金 = JP 池 ×3
  • 每注 5% 貢獻到 JP 池累積

【快捷鍵（測試用）】

  • Space = SPIN
  • F = 觸發 Free Game
  • T = 穿門特效 / W = 碰壁特效
  • C = Combo / B = Big Win
  • S = Scatter Reveal
