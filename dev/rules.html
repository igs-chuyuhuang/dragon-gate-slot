射龍門 Slot

🎰 Main Game 規則

3×3 盤面，每列獨立判定射龍門。每局扣 bet，平均分配到 3 列。

✅ 穿門範例

＜ ＜

3 < 5 < 8 → 穿門！贏得 bet/3 × 倍率 + 歸還本金

❌ 碰壁範例

＝ ＜

中間牌 = 左牌 → 碰壁！扣 bet/3

❌ 未中範例

＞

9 > 8 → 在門外！扣 bet/3

💰 穿門倍率表

門類型Gap倍率

普通門4~7×2
寬門8+×1

🐉 Scatter 收集

盤面隨機出現龍珠 Scatter，每個 +1

碰壁 -1，同值碰壁 -2

收集滿 10 個可選擇進入 Free Game 或 Bonus Game

碰壁 → Scatter -1

＝ ＜

中間牌 = 左牌 → 碰壁！Scatter -1

同值碰壁 → Scatter -2

＝ ＝

三張同值 → 同值碰壁！Scatter -2

🐲 Free Game

  • 8 轉免費遊戲
  • 中輪帶有獎勵符號（依 bet 大小決定）
  • 穿門時獲得對應金額獎勵

🎰 Bonus Game

  • 12 局射龍門
  • 初始籌碼 = bet × 2
  • 穿門：贏得下注金額（×1）
  • 碰壁：扣 2 倍下注
  • 同值碰壁：扣 3 倍下注
  • 未中：扣 1 倍下注
  • All in 輸：歸零只拿回初始籌碼，遊戲結束
  • 12 局結束後，獲得累積贏分；若贏分低於初始籌碼，則保底拿回初始籌碼

🏆 Jackpot 彩金

3 列全為窄門或極窄門時有機會觸發！

  • 中輪三格帶上 JP 符號
  • 三格同色 = 贏走對應彩金池
  • 極窄門：GRAND + MAJOR + MINI 都可能
  • 窄門：只有 MAJOR + MINI
  • 下注越大，JP 符號出現機率越高
