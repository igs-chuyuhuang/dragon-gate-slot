## 1. 配色差異

**目前狀態：** 墨黑底色為主，金色文字/邊框，整體偏暗沉
**目標狀態：** 翡翠綠 + 中國紅 + 金色三色體系，明亮華麗
**需要做的事：**
- 將所有黑色底色替換為翡翠綠或深紅色
- 增加紅色元素（操作列、盤面內底色、匾額）
- 保留金色但升級為浮雕質感（非扁平金色）
- 整體色調從「暗黑金」轉為「翡翠紅金」

---

## 2. 背景氛圍差異

**目前狀態：** 暗色模糊中式宮殿門樓，整體陰沉，缺乏層次
**目標狀態：** 明亮黃昏荷花池仙境，溫暖光線，豐富場景元素
**需要做的事：**
- 重新生成背景：荷花池 + 石階 + 遠景宮殿群 + 粉橘天空
- 加入場景元素：粉色蓮花、金色錦鯉躍水、飄落櫻花瓣
- 加入紅色宮燈（兩側懸掛，發光效果）
- 加入「福」字大燈籠
- 整體光線改為暖色黃昏調
- 加入薄霧/仙氣效果

---

## 3. UI 厚度與質感差異

**目前狀態：** CSS 扁平設計，無材質感，按鈕為簡單色塊
**目標狀態：** 立體精緻，所有 UI 元素有材質（玉石、金屬、紅漆）
**需要做的事：**
- SPIN 按鈕：改為大型紅玉圓形 + 金色浮雕外圈
- +/- 按鈕：改為深綠圓形 + 金色邊框
- 功能按鈕：改為圓角矩形深綠底 + 金色邊框 + 金色圖標
- 所有文字改為金色帶陰影
- 面板背景加入材質紋理（非純色）

---

## 4. Symbol 一致性差異

**目前狀態：** Python PIL 在黑底模板上疊金色文字（扁平、無質感）
**目標狀態：** 翡翠玉石底板 + 金色浮雕文字（立體、有光澤）
**需要做的事：**
- 重新設計 symbol 底板：翡翠玉石質感（帶雲紋暗紋）
- 文字改為金色浮雕效果（凸起感、金屬高光、陰影）
- 每個 symbol 加獨立金色如意紋邊框
- 邊框四角加翡翠圓珠裝飾
- Scatter 龍：改為紅底金龍圓形設計
- 可能需要改用 AI 生成或更複雜的 PIL 合成流程

---

## 5. Slot 主框設計差異

**目前狀態：** 簡單金色矩形邊框（CSS border），無造型
**目標狀態：** 龍門牌坊造型（琉璃瓦屋頂 + 龍柱 + 翡翠基座）
**需要做的事：**
- 設計龍門牌坊外框素材：
  - 頂部：綠色琉璃瓦飛簷 + 紅色匾額「射龍門」+ 金龍頭
  - 兩側：金色龍柱（雕龍纏繞）
  - 底部：翡翠玉石基座 + 石階
- 盤面內部背景改為深紅色
- 格子分隔改為金色十字裝飾條 + 翡翠珠交叉點
- 整體從「平面框」升級為「立體建築結構」

---

## 6. 左右資訊面板差異

**目前狀態：** 無側邊面板，所有資訊擠在底部
**目標狀態：** 深綠金邊面板，分區顯示遊戲狀態資訊
**需要做的事：**
- 設計右側面板（手機版 + 桌面版）：
  - 龍門倍率（龍×1）
  - 穿門獎勵（+13）
  - 幸運龍狀態
- 設計左側面板（桌面版）：
  - 龍之寶庫（Free Game 計數器）
  - 龍珠收集進度（3/10）
  - 連線獎勵顯示
- 面板風格：深綠底 + 金色邊框 + 金色文字
- 需要配合程式前端調整佈局

---

## 7. 底部操作列差異

**目前狀態：** 深色/黑色底部欄，扁平按鈕，文字白色
**目標狀態：** 中國紅底色 + 金色上邊框裝飾 + 立體按鈕
**需要做的事：**
- 底部欄背景改為中國紅
- 上方加金色裝飾邊條
- 餘額/投注/贏分文字改為金色
- SPIN 按鈕放大，改為紅玉質感圓形 + 金色外圈
- +/- 按鈕改為深綠圓形 + 金色邊
- 整體從「功能性」升級為「裝飾性+功能性」

---

## 8. 整體商業完成度差異

**目前狀態：** Prototype 等級（3/10）
- 能跑、能玩，但視覺上一看就是開發中版本
- 缺乏品牌識別（無吉祥物、無特色外框）
- 缺乏氛圍營造（暗色、無場景感）
- UI 功能正確但視覺粗糙

**目標狀態：** 商業上線等級（9/10）
- 第一眼就有「高品質手遊」的感覺
- 強烈品牌識別（龍門牌坊 + 小龍 + 翡翠色系）
- 沉浸式場景（荷花池仙境）
- 每個 UI 元素都有精緻材質和裝飾

**需要做的事：**
- 全面重製美術素材（非微調，是重做）
- 新增大量裝飾元素（龍柱、燈籠、荷花、錦鯉）
- 新增吉祥物小龍
- 重新設計所有 UI 元素的視覺風格
- 配合程式前端重新搭建場景佈局

## 10. 技術路線建議

- **AI 生成（Pollinations.ai / Midjourney）：** 背景場景、龍門牌坊、吉祥物、Scatter 龍
- **PIL 合成：** Symbol（需升級為玉石底板+浮雕效果）、UI 元素拼合
- **CSS/程式：** 佈局調整、面板位置、響應式適配
- **手繪/精修：** 可能需要對 AI 生成素材做後期調整

> ⚠️ 這是一次「全面美術升級」而非「微調」。預計需要重新生成/製作大部分素材。
