## 提案 1：龍息連擊（Dragon Breath Combo）

### 玩家看到什麼
連續穿門時，龍從背景飛出，每次連擊龍身越長、火焰越旺。連擊計數器以燙金數字顯示在畫面中央，3 連擊以上螢幕邊緣燃起金色火焰。

### 玩家做什麼
正常 Spin，但連續穿門（跨轉累計）會觸發連擊加成。玩家會想「再一轉！」維持連擊。

### 數學模型影響
- 2 連擊：當轉賠率 ×1.2
- 3 連擊：×1.5
- 5 連擊以上：×2.0
- 連擊斷裂時重置。對 RTP 影響約 +1.2%，可從碰壁賠率微調回收。

### 需要的美術/音效
- 龍身動畫（3 段：短龍/中龍/長龍）
- 火焰粒子特效
- 連擊音效（音高遞增的打擊音）
- 連擊斷裂音（龍嘶吼消散）

### 開發難度
**低** — 只需追蹤連擊計數器 + 乘數套用，UI 動畫獨立於核心邏輯。

### Demo 展示價值
🎯 連擊 5 次時龍身環繞整個螢幕 + 爆炸音效，30 秒內最直覺的「爽感遞增」體驗。

## 提案 2：龍門風暴（Gate Storm Event）

### 玩家看到什麼
隨機觸發（約每 50 轉一次），天空烏雲密布、閃電劈下，接下來 3 轉所有門寬 +2 級（窄門變中門、中門變寬門），畫面持續閃電特效。

### 玩家做什麼
風暴觸發時加大押注（如果有膽量），因為穿門機率大幅提升。3 轉內盡量把握機會。

### 數學模型影響
- 門寬 +2 級 = 穿門率提升約 20~30%，但賠率對應降低
- 淨 EV 約 +15% per spin × 3 轉 = 對整體 RTP 影響 < 0.5%
- 觸發率可調控

### 需要的美術/音效
- 烏雲 + 閃電背景動畫
- 門框發光擴大動畫
- 雷鳴音效 + 風暴環境音（3 轉持續）
- 風暴結束：雲散日出

### 開發難度
**低** — 臨時修改門寬判定參數 3 轉後還原，加 overlay 動畫。

### Demo 展示價值
🎯 突然的天氣變化打破節奏單調感，閃電劈下瞬間全場注意力集中。

## 提案 3：金龍獻瑞（Golden Dragon Wild）

### 玩家看到什麼
Free Game 期間，隨機一格變成金龍 Wild 符號（全金發光），該格自動取「對玩家最有利的牌值」。金龍出現時有專屬 3 秒動畫：龍從門中飛出、盤旋、落定。

### 玩家做什麼
進入 Free Game 後期待金龍出現。金龍出現在中欄 = 保證穿門；出現在左/右欄 = 門寬最大化。

### 數學模型影響
- Free Game 每轉 15% 機率出現 1 個 Wild
- 平均提升 Free Game 累積分數約 +12%
- 已計入 JP 門檻設計，不需調整門檻

### 需要的美術/音效
- 金龍符號（獨立美術，區別於 Scatter 龍）
- 金龍飛入動畫（粒子拖尾）
- 專屬音效（古箏滑音 + 金屬碰撞）

### 開發難度
**中** — 需要 Wild 替代邏輯（遍歷所有可能值取最優），但只在 FG 模式生效。

### Demo 展示價值
🎯 金龍飛出的瞬間是 Free Game 的高潮記憶點，評審一看就懂「這是好事」。

## 提案 4：龍門試煉（Gate Challenge Mini-Game）

### 玩家看到什麼
Free Game 結束、進入 JP 判定前，出現一個「射龍門」小遊戲畫面：三道門（Basic/Major/Grand）立在遠方，玩家的累積分數化為一顆火球，火球飛向對應的門。

### 玩家做什麼
按下「射門」按鈕決定發射時機（純演出，結果已由分數決定），但按鈕的「力道感」讓玩家覺得自己參與了結果。畫面會根據按壓時長顯示不同力道動畫。

### 數學模型影響
**零影響** — 純演出包裝，結果完全由累積分數決定。但玩家感受到「我射進去的」。

### 需要的美術/音效
- 三道龍門立體透視圖
- 火球飛行軌跡動畫
- 命中門框爆炸特效（分 3 級華麗度）
- 未命中：火球熄滅落地
- 音效：蓄力音 → 發射音 → 命中爆炸音

### 開發難度
**中** — 需要獨立場景/overlay + 動畫時間軸，但不影響數學邏輯。

### Demo 展示價值
🎯 這是整場 Demo 的「大結局」時刻。火球射入 Grand JP 門的爆炸動畫 = 全場最記憶深刻的畫面。

## 提案 5：碰壁反彈（Wall Bounce）

### 玩家看到什麼
碰壁時，牌面不是靜態顯示「碰壁」，而是中欄的牌「撞」到門框彈回來，彈回時有 20% 機率「破壁」— 門框碎裂，變成穿門！畫面震動 + 碎片飛散。

### 玩家做什麼
碰壁不再是純負面結果，玩家會期待「會不會破壁？」增加每次碰壁的懸念感。

### 數學模型影響
- 碰壁原本 ×1.2 賠率（目前代碼是 -2 倍扣款）
- 破壁機率 20%：碰壁 → 穿門（取該門寬賠率）
- 淨效果：碰壁 EV 從 -2× 變為 (-2×0.8 + 穿門賠率×0.2)
- 可微調破壁率控制 RTP

### 需要的美術/音效
- 牌面撞擊門框動畫
- 門框碎裂粒子效果
- 撞擊音 → 碎裂音（成功）/ 彈回音（失敗）
- 螢幕震動（Screen Shake）

### 開發難度
**低** — 碰壁判定後加一次隨機檢查，成功則改判穿門。動畫獨立處理。

### Demo 展示價值
🎯 「碰壁居然能破壁！」的驚喜反轉，讓觀眾發出「哦！」的瞬間。

## 提案 6：龍珠收集（Dragon Pearl Collection）

### 玩家看到什麼
畫面上方有 7 個龍珠槽位（七龍珠致敬）。每次穿門成功，對應門寬等級的龍珠亮起一顆。集滿 7 顆觸發「神龍降臨」— 下一轉三列全部保證穿門。

### 玩家做什麼
追蹤龍珠進度，感受「快集滿了！」的期待感。集滿瞬間的儀式感讓玩家截圖分享。

### 數學模型影響
- 平均約 25~30 轉集滿一次（依穿門率）
- 神龍降臨：3 列保證穿門，期望值約 6~12× 押注
- 對 RTP 貢獻約 +2%，可從基礎賠率微調回收

### 需要的美術/音效
- 7 顆龍珠 UI（漸亮動畫）
- 神龍降臨全屏動畫（3 秒）
- 集珠音效（叮！遞增音高）
- 神龍咆哮音效

### 開發難度
**低** — 計數器 + 條件觸發 + 強制穿門邏輯（覆寫隨機結果）。

### Demo 展示價值
🎯 龍珠集滿 → 神龍降臨的儀式感，是最容易讓評審理解的「收集→獎勵」循環。

## 提案 7：同值逆轉（Same Value Reversal）

### 玩家看到什麼
同值命中（原本 -3× 扣款）時，畫面先顯示「💀 危險！」紅色警告，然後出現一個快速反應按鈕「🛡️ 擋！」。玩家有 1.5 秒按下，成功則傷害減半並獲得 1 顆龍珠。

### 玩家做什麼
同值命中瞬間快速按下防禦按鈕。增加互動性，把最痛苦的時刻變成「還好我反應快」的成就感。

### 數學模型影響
- 同值命中率 0.59%/列，極低頻
- 成功防禦：-3× → -1.5×（減半）
- 假設 70% 玩家能按到：對 RTP 影響 < 0.1%

### 需要的美術/音效
- 紅色警告閃爍 + 防禦盾牌按鈕
- 成功：盾牌碎裂但擋住攻擊動畫
- 失敗：全額扣款 + 心碎音效
- 倒數計時環形進度條

### 開發難度
**低** — 同值命中後插入 1.5 秒互動視窗，結果修改扣款倍數。

### Demo 展示價值
🎯 唯一需要玩家「動手」的時刻，打破被動觀看的節奏，評審會記住這個互動設計。

## 提案 8：門神守護（Gate Guardian Bonus）

### 玩家看到什麼
每 100 轉（或隨機），門神（秦叔寶/尉遲恭）從兩側門框走出，宣布「門神加持」。接下來 5 轉，碰壁不扣款反而給 ×0.5 獎勵，且穿門賠率 +1 級。

### 玩家做什麼
門神出現時感受到「被保護」的安心感，大膽押注。這是低谷期的情緒救贖機制。

### 數學模型影響
- 碰壁從 -2× 變為 +0.5×（5 轉內）
- 穿門賠率 +1 級（如 2× → 4×）
- 觸發率 1%/轉，5 轉持續 = 對 RTP 影響約 +0.8%

### 需要的美術/音效
- 門神角色立繪（左右各一）
- 門神登場動畫（從門框走出）
- 守護光環持續特效
- 古風鼓點 + 號角音效

### 開發難度
**中** — 需要狀態機追蹤門神 buff 持續轉數 + 修改碰壁/穿門計算。

### Demo 展示價值
🎯 中國風角色登場的儀式感，視覺辨識度極高，一眼就知道「這是中國風 Slot」。

## 提案 9：龍門加速（Turbo Gate Rush）

### 玩家看到什麼
Free Game 最後 3 轉，畫面切換為「加速模式」— 轉軸速度 ×3、背景變為衝刺隧道、音樂節奏加快。每轉結果快速閃過，累積分數瘋狂跳動。

### 玩家做什麼
感受最後衝刺的緊張感。不需要額外操作，但視覺節奏的加速讓玩家心跳加快，強化「最後關頭」的戲劇性。

### 數學模型影響
**零影響** — 純演出節奏變化，數學邏輯不變。最後 3 轉的結果照常計算。

### 需要的美術/音效
- 速度線 / 隧道背景動畫
- 加速版轉軸動畫（縮短停止間隔）
- 音樂 BPM 加倍 + 心跳音效
- 最後一轉：慢動作 + 定格

### 開發難度
**低** — 只需在 FG 最後 3 轉修改動畫時間參數 + 切換背景。

### Demo 展示價值
🎯 節奏變化是最容易感受到的「遊戲設計功力」，評審會注意到「這團隊懂節奏」。

## 提案 10：大龍門開啟儀式（Grand Gate Ceremony）

### 玩家看到什麼
Free Game 結束進入 JP 判定時，不是直接顯示結果，而是：
1. 畫面暗下，只剩累積分數在中央發光
2. 三道龍門從遠方緩緩升起（小→中→大）
3. 分數化為光柱，光柱高度對應分數
4. 光柱觸及哪道門 = 命中哪層 JP
5. 命中瞬間：門框爆開 + 金幣雨 + 對應 JP 名稱全屏顯示

### 玩家做什麼
屏息等待光柱升到哪裡。這是純觀賞的「開獎儀式」，但張力極強。

### 數學模型影響
**零影響** — 純演出包裝，結果由累積分數決定。

### 需要的美術/音效
- 三道龍門 3D 透視升起動畫
- 光柱上升動畫（速度先快後慢，製造懸念）
- 命中爆炸特效（3 級：銅/銀/金）
- 金幣雨粒子系統
- 音效：鼓點漸強 → 命中爆炸 → 勝利號角
- 未達門檻：光柱熄滅 + 安慰音效

### 開發難度
**中** — 需要完整的過場動畫時間軸，但不影響遊戲邏輯。可用 Timeline/DOTween 實現。

### Demo 展示價值
🎯 **這是整個 Demo 的王牌時刻。** 光柱命中 Grand JP 門的瞬間 = 全場起立鼓掌的設計。30 秒 Demo 的最後 10 秒就放這個。

## 30 秒 Demo 腳本建議

1. **0~5 秒**：正常 Spin，展示基本穿門判定
2. **5~12 秒**：連續穿門觸發龍息連擊（#1），火焰越來越旺
