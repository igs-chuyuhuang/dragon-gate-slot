# Visual QA Report — 射龍門 Slot V2

> 日期：2026-05-25
> 版本：V2
> 測試環境：Playwright Chromium headless, 390×844 (mobile) + 1280×720 (desktop)
> 對標：PG Soft、Pragmatic Play、NetEnt

## 總評

**6.5 / 10** — V2 相比 V1 有明顯進步：symbol 重疊 bug 已修復、特效系統完整（穿門/碰壁/Combo/Big Win/JP 揭曉皆有）、整體國潮視覺風格統一。但離市場級仍有差距，主要在動畫精緻度、粒子豐富度、文字特效品質。

---

## 各項評估

### 1. 整體 UI / 盤面
- **現狀：** 3×3 盤面清晰，國潮紅金卡牌風格統一。背景為中式宮殿門樓，紅燈籠裝飾。JP 三層顯示在頂部，下方有餘額/下注/贏分面板。
- **問題：** 盤面邊框較粗佔空間；手機版下方資訊區偏擠；桌面版背景兩側龍雕像很有氣勢但盤面佔比偏小。
- **建議：** 桌面版盤面可再放大 10-15%；手機版結算文字區可用 overlay 取代固定區塊。
- **評分：** 7/10

### 2. Symbol 素材
- **現狀：** 13 張牌面（A-K）+ Scatter 龍，圖片清晰無重疊（5/22 已修復 cell-label bug）。金色數字/字母在深色底上辨識度高。Scatter 龍金色立體感佳。
- **問題：** 低牌（2-9）視覺差異不大，都是「金框+數字」；缺少高牌專屬圖案（如龍鳳麒麟）來拉開層次。
- **建議：** 高牌（J/Q/K/A）可加入專屬角色圖案，增加辨識度和收藏感。
- **評分：** 6.5/10

### 3. Spin 動畫
- **現狀：** 垂直滾動 strip 動畫，有 overshoot bounce 停軸效果。三列依序停止有時間差。
- **問題：** 缺少按下 SPIN 的蓄力感（anticipation）；停軸 bounce 幅度偏小；三列間隔可再拉長增加期待感。
- **建議：** 加入 spin button 按壓縮放 + 轉軸啟動延遲；停軸加 hit-stop（20ms 凍結）+ 更大 bounce。
- **評分：** 6/10

### 4. 穿門特效 (Gate Through)
- **現狀：** 觸發時全螢幕金色 flash + 「再一龍！」文字 + ×1 倍率顯示 + 火花粒子。整行高亮。
- **問題：** 金色 flash 太強烈（幾乎全白），遮蓋了盤面細節；「再一龍！」文字缺少動態入場（直接出現）；火花粒子偏少。
- **建議：** flash 透明度降低 30%；文字加入 scale bounce 入場；增加火花粒子數量和軌跡多樣性。
- **評分：** 7/10

### 5. 碰壁特效 (Wall Hit)
- **現狀：** 觸發時中間 cell 有紅色爆炸光點。
- **問題：** 特效持續時間極短（<200ms），幾乎看不到；缺少裂痕紋理、震動反饋；沒有音效配合的視覺節奏。
- **建議：** 加入盤面震動（camera shake）+ 裂痕 overlay 持續 500ms + 紅色邊框閃爍。
- **評分：** 4/10

### 6. Combo 系統
- **現狀：** 連續穿門觸發 Combo，有「2 COMBO!」「4 COMBO!」大字 + ×5 倍率 + 星星粒子 + 全螢幕金色光暈。
- **問題：** Combo 文字與倍率分開顯示，視覺焦點分散；高 Combo 時金色光暈太濃導致盤面不可見。
- **建議：** 文字和倍率合併為一組動畫（如「4 COMBO ×5」）；光暈透明度隨 combo 數漸增但不超過 70%。
- **評分：** 7/10

### 7. Big Win
- **現狀：** 「龍門狂熱」+ 龍 emoji 橫幅 + 數字跳動計數（234→716→800）+ 頂部 confetti 粒子。
- **問題：** 「DRAGON」英文文字被截斷（只顯示一半）；龍 emoji 太小不夠氣勢；數字計數缺少最終定格的爆發感。
- **建議：** 修復文字截斷；用大龍圖片取代 emoji；數字到達最終值時加 scale pulse + 金幣噴射。
- **評分：** 6/10

### 8. Scatter 揭曉
- **現狀：** 從截圖看，Scatter 觸發時沒有獨立的揭曉動畫（被 Big Win 計數覆蓋）。盤面上 Scatter 龍圖片本身有金色邊框。
- **問題：** 缺少 Scatter 落定時的專屬動畫（如龍吼 + 震動 + 光柱）；多個 Scatter 沒有逐一揭曉的節奏。
- **建議：** 每個 Scatter 落定時加入 0.5s 的光柱 + 震動 + 音效；3 個 Scatter 集齊後再觸發 Free Game 轉場。
- **評分：** 5/10

### 9. JP 揭曉 (Jackpot Reveal)
- **現狀：** 全螢幕垂直進度條，三層標記（BASIC 藍/MAJOR 橙/GRAND 紅），光標從底部上升，顯示「85 分」。底部有發光方塊。
- **問題：** 進度條設計獨特有創意，但視覺偏簡陋（純色線條+方塊）；缺少背景暗化的層次感；「分」字不夠國際化。
- **建議：** 進度條加入漸層和發光效果；背景加深色 overlay；到達各層時加爆發動畫；文字改為金額顯示。
- **評分：** 6.5/10

### 10. 桌面版適配
- **現狀：** 1280×720 下盤面置中，背景完整顯示（宮殿+龍雕像+燈籠），UI 元素比例合理。穿門特效在桌面版也正常運作。
- **問題：** 盤面左右留白較多；SPIN 按鈕在桌面版偏小；缺少桌面版專屬的側邊資訊面板。
- **建議：** 盤面可放大或加入側邊歷史記錄面板；SPIN 按鈕放大 20%。
- **評分：** 7/10
