# Visual QA Report — 射龍門 Slot

> 日期：2026-05-21
> 測試環境：Playwright Chromium headless, 390×844 (mobile) + 1280×720 (desktop)
> 對標：市面線上老虎機（如 PG Soft、Pragmatic Play、NetEnt）

## 總評

**5 / 10** — 已有基本特效框架和視覺風格，但離市場級仍有明顯差距。主要缺失：缺乏粒子多樣性、動畫節奏感不足、文字特效缺少描邊/漸層、部分特效持續時間太短難以感知。

## 各特效評估

### 1. Spin 轉軸動畫
- **現狀描述：** 格子內圖片快速切換模擬滾動，停止時有 bounce 彈跳動畫。牌面圖片（國潮風紅金卡牌）清晰可辨。
- **問題：**
  - 沒有真正的垂直滾動位移感（只是圖片切換 + blur）
  - 缺少 anticipation（按下 SPIN 前的蓄力感）
  - 停軸沒有 hit stop（短暫凍結）
  - 三列停止間隔太短，缺少期待感
- **改善建議：**
  - 改為真正的 translateY 垂直滾動條帶
  - 加入 SPIN 按下時的 0.3s 蓄力壓縮動畫
  - 每列停止時加 50ms hit stop + 輕微 board shake
  - 三列停止間隔拉長到 400/800/1200ms

### 2. 穿門成功 (T)
- **現狀描述：** 中央出現金色火球爆炸 + 「×4」倍率文字，全螢幕金色 overlay 閃爍，持續約 300ms。
- **問題：**
  - 火球只有單一形狀，缺少粒子擴散
  - 倍率文字沒有描邊/glow，在亮背景下可能不清晰
  - 特效持續時間太短（150ms 後已消失）
  - 缺少 anticipation → impact → settle 的三段節奏
- **改善建議：**
  - 火球加入多層粒子（火花 + 光圈 + 殘影）
  - 倍率文字加金色漸層 + 黑色描邊 + 放大彈出動畫
  - 特效持續拉長到 800ms（200ms 展開 + 400ms 持續 + 200ms 消散）
  - 加入穿門瞬間的 board shake（3px, 100ms）

### 3. 碰壁 (W)
- **現狀描述：** 碰壁格子出現小型紅/橙色衝擊光點，範圍很小，僅限單格內。
- **問題：**
  - 特效太小太弱，幾乎看不到
  - 缺少裂痕/碎片視覺
  - 沒有 board shake
  - 沒有音效回饋的視覺對應（閃爍/震動）
- **改善建議：**
  - 加入裂痕 SVG 疊加在碰壁格子上（持續 1s 後淡出）
  - 碰壁瞬間 board shake（2px, 80ms）
  - 碰壁格子邊框閃紅 2 次
  - 加入碎片粒子從碰壁點向外擴散

### 4. Combo 連擊 (C)
- **現狀描述：** 顯示「×3 2 COMBO」大字，金色粒子散佈，全螢幕金色 overlay。文字佔據盤面中央。
- **問題：**
  - 文字沒有描邊，在金色背景上對比度不足
  - 粒子形狀單一（只有圓點）
  - 缺少連擊遞增的視覺強化（2 combo 和 5 combo 看起來一樣）
  - 沒有 hit stop 感
- **改善建議：**
  - COMBO 文字加黑色描邊 + 金色漸層
  - 隨 combo 數增加：粒子密度增加、文字放大、shake 強度增加
  - 加入 50ms hit stop（畫面短暫凍結）再展開特效
  - 粒子加入星形、菱形等多種形狀

### 5. Big Win (B)
- **現狀描述：** 畫面壓暗，出現「龍門」綠色文字 + 龍圖標在盤面右下角。背景明顯變暗。
- **問題：**
  - 「龍門」文字被截斷（只看到部分），定位偏右超出螢幕
  - 文字用綠色而非金色，與整體金紅色調不搭
  - 缺少大型數字 countup 動畫
  - 沒有金幣/寶石飛散的慶祝粒子
- **改善建議：**
  - 文字置中顯示，改為金色 + 紅色描邊
  - 加入大型贏分數字 countup（從 0 滾到最終金額）
  - 加入金幣粒子從上方灑落
  - 背景壓暗程度加深到 80%

### 6. Scatter Reveal (S)
- **現狀描述：** 畫面大幅壓暗，出現「DRA」文字（被截斷）+ 龍圖標 + 大型數字 countup（114 → 800），金色粒子散佈。
- **問題：**
  - 「DRAGON」文字被截斷，只顯示「DRA」
  - 數字 countup 位置偏低，與控制台重疊
  - 龍圖標太小
  - 缺少 Scatter 符號逐一亮起的揭曉動畫
- **改善建議：**
  - 文字完整顯示或改用更短的標題（如「FREE GAME!」）
  - 數字 countup 置中在盤面區域
  - 加入 Scatter 符號逐一放大 + 金色光圈的揭曉序列
  - 龍圖標放大 + 飛入動畫

### 7. JP Basic (1)
- **現狀描述：** 右側出現垂直溫度計/進度條，標示 Grand/Major/Basic 三層，底部顯示「進入 Basic」文字。進度條有紅→橙→黃漸層。
- **問題：**
  - 進度條在手機上偏右，部分被截斷
  - 缺少分數跳動的動畫感
  - 沒有命中 JP 門時的爆發特效
  - 整體太靜態，缺少 anticipation（分數逐漸上升的緊張感）
- **改善建議：**
  - 進度條改為全螢幕 overlay，置中顯示
  - 分數上升時加入逐格跳動 + 音效節拍
  - 命中 JP 門時加入爆發光效 + 文字彈出
  - 加入「即將進入 Major！」的預告提示

### 8. JP Grand Perfect (5)
- **現狀描述：** 同 JP Basic 的溫度計 UI，右側顯示三層標籤，進度條填充更高。
- **問題：**
  - 與 JP Basic 視覺差異不大（應該更震撼）
  - Grand Perfect 是最高獎項，但特效強度不夠
  - 缺少「精準命中中心」的特殊慶祝
  - 沒有全螢幕爆發 + 金幣雨
- **改善建議：**
  - Grand Perfect 應有獨立的全螢幕慶祝動畫
  - 加入多段揭曉：Basic → Major → Grand 逐層點亮
  - 精準命中時全螢幕金色爆發 + 「PERFECT!」大字
  - 加入持續 3-5 秒的金幣雨 + 煙火粒子

## 共通問題

1. **特效持續時間太短** — 大部分特效在 150-300ms 內結束，玩家來不及感知。市面遊戲通常 800ms-2s。
2. **缺少 hit stop** — 沒有任何特效有短暫凍結感，導致 impact 感不足。
3. **文字特效缺少描邊/漸層** — 所有文字都是純色，在複雜背景上辨識度低。
4. **粒子形狀單一** — 只有圓形光點，缺少星形、菱形、火花等多樣性。
5. **Board shake 缺失** — 穿門、碰壁、combo 都沒有盤面震動回饋。
6. **定位問題** — 部分特效（Big Win 文字、JP 進度條）在手機上被截斷或偏移。
7. **缺少 anticipation → impact → reward → settle 四段節奏** — 特效直接出現直接消失，沒有蓄力和餘韻。
8. **JP 揭曉缺少多段遞進** — 應該有從低到高逐層揭曉的緊張感。

## 優先改善項目（Top 5）

1. **延長特效持續時間 + 加入 hit stop** — 所有特效至少 800ms，impact 瞬間加 50ms 凍結。影響：全局體感提升。
2. **文字特效升級** — 所有倍率/金額文字加金色漸層 + 黑色描邊 + glow + 放大彈出。影響：辨識度和高級感。
3. **Board shake 系統** — 穿門(3px)、碰壁(2px)、combo(4px)、JP(5px) 不同強度震動。影響：打擊感。
4. **JP 多段揭曉重做** — 改為全螢幕 overlay + 分數逐格上升 + 逐層點亮 + 命中爆發。影響：最高潮體驗。
5. **修正定位問題** — Big Win 文字置中、JP 進度條改全螢幕、Scatter 文字不截斷。影響：手機可用性。
