## 主遊戲機制

### 射龍門判定規則

#### 正常門（左 ≠ 右）

| 條件 | 結果 | 效果 |
|------|------|------|
| 中欄落在左右界之間 | 穿門 ✓ | 依門寬賠率派彩 |
| 中欄 = 左或右界值 | 碰壁 | 不扣錢，扣 1 個 Scatter 累積燈 |
| 中欄超出範圍 | 未穿 | 無事發生 |

#### 同值門（左 = 右）

| 條件 | 結果 | 效果 |
|------|------|------|
| 中欄 = 同值 | 同值撞柱 | 不扣錢，扣 2 個 Scatter 累積燈 |
| 中欄 ≠ 同值 | 未穿 | 無事發生 |

> 碰壁與同值撞柱不再扣款，改為扣 Scatter 累積燈號（延遲觸發 FG/BG 的懲罰）。

#### Scatter（龍符號）— 累積收集制

盤面每出現 1 個 Scatter（龍符號），累積燈號 +1。累積到門檻後觸發選擇畫面。

**累積規則：**
| 事件 | 燈號變化 |
|------|---------|
| 盤面出現 Scatter | +1（每顆獨立計算） |
| 碰壁（中欄 = 界值） | −1 |
| 同值撞柱（左=右=中） | −2 |

- 累積燈最低為 0，不會變成負數
- 觸發後燈號歸零，重新收集

**觸發門檻：** ⚠️ 待數學模型確認（暫定 10 個）

**觸發後：** 跳出選擇畫面，玩家二選一：
- **進入 Free Game**：盤面出現帶彩金數字的特殊 symbol，穿門成功直接獲得該 symbol 上顯示的彩金金額
- **進入 Bonus Game**：8 轉累積模式，累積點數對照三層 JP 門

**待數學模型評估：**
- 累積門檻應設多少個？（10？15？）
- 每格 Scatter 出現率是否需調整？（目前 5%）
- 碰壁扣 1 / 同值扣 2 設計下，平均多少轉觸發一次？
- 此設計對 RTP 的影響

> UI 表現：畫面上方或側邊顯示累積燈號進度條，每次 +1 有亮燈動畫，扣燈有熄滅動畫。

## Free Game — 彩金穿門

### 流程

1. **累積燈號達門檻** → 玩家選擇 Free Game
2. 盤面上出現帶彩金數字的特殊 symbol（顯示具體金額）
3. **不會出現 Scatter**（龍符號不出現在 Free Game 中）
4. **不會有碰壁**（只有「中彩金」或「沒中彩金」兩種結果）
5. 中彩金 → 直接獲得該 symbol 上顯示的彩金金額（不依門寬窄調整賠率）
6. 沒中彩金 → 不獲得該列彩金

> 設計邏輯：Free Game 是純獎勵模式，簡化判定為「中 or 不中」，中了就拿門上顯示的金額，直觀爽快。

## Bonus Game — 大龍門挑戰系統

### 流程

1. **累積燈號達門檻** → 玩家選擇 Bonus Game
2. 進入 **8 轉**累積模式
3. 每轉結果：穿門（牌值 × 1）+ 碰壁（牌值 × 3）+ 未穿（0 點）= 累積總點數 X
4. Bonus Game 結束 → 大龍門開啟，以 X 對照三層門

### JP 門對照

| 條件 | 結果 |
|------|------|
| 累積點數 < 60 | 保底小彩金 |
| 🔵 Basic JP 門：60 ~ 120（中心 90） | 命中中心 → Basic JP × 3 |
| 🟠 Major JP 門：130 ~ 200（中心 165） | 命中中心 → Major JP × 3 |
| 🔴 Grand JP 門：210 ~ 320（中心 265） | 命中中心 → Grand JP × 3 |
| 累積點數 > 320 | 保底中彩金 |

> 設計邏輯：累積點數越高挑戰越大的 JP 門。超出 Grand JP 不會落空，保底中彩金確保玩家不因表現太好而損失期待感。命中各層中心值可獲得 3 倍加乘。

## Main Game 結算顯示

- 每一欄（列）旁邊直接顯示該列的結果
- 穿門：顯示贏得金額（如 +60）
- 碰壁：顯示「扣 1 燈」（🔥 -1）
- 同值撞柱：顯示「扣 2 燈」（🔥 -2）
- 未穿：顯示 ✗ 或不顯示
- 讓玩家一目了然每列的結果

## 彩金池動畫

- 上方 JP 三層數字持續跳動動畫（模擬彩金不斷增加的感覺）
- 每 10 秒實際增加一點金額到彩金池（視覺上持續累積）
- 增加時有微小的 pulse 動畫強調變化
