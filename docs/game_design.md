## 主遊戲機制

### 射龍門判定規則

#### 正常門（左 ≠ 右）

| 條件 | 結果 | 賠率 |
|------|------|------|
| 中欄落在左右界之間 | 穿門 ✓ | 依門寬賠率 |
| 中欄 = 左或右界值 | 碰壁 | −2 倍（玩家賠機台） |
| 中欄超出範圍 | 未穿 | × 0 |

#### 同值門（左 = 右）

| 條件 | 結果 | 賠率 |
|------|------|------|
| 中欄 = 同值 | 玩家賠莊家 | −3 倍（扣款）⚠️ |
| 中欄 ≠ 同值 | 判輸 | × 0 |

> 同值邊界（AA / KK 等）= 龍門關閉。若中欄剛好命中同值，玩家需賠莊家 3 倍押注（扣款）。投注前系統自動檢查餘額 ≥ 10× 押注，不足時禁止下注。

#### Scatter（龍符號）

- 盤面出現 3 個龍 → 跳出選擇畫面，玩家二選一：
  - **進入 Free Game**：盤面出現帶彩金數字的特殊 symbol，穿門成功直接獲得該 symbol 上顯示的彩金金額
  - **進入 Bonus Game**：8 轉累積模式，累積點數對照三層 JP 門
- 每格出現率 5%，平均每 122 轉觸發一次

## 數學模型

### RTP 96.4% 分配（實測）

| 來源 | 佔比 |
|------|------|
| 主遊戲直接賠付（穿門賠率 − 碰壁×2 − 同值×3） | 71.7% |
| JP 系統（Bonus Game 決勝） | 24.7% |
| **合計** | **96.4%** |

### JP 彩金池參數

| JP 層級 | 初始值 | 上限 |
|---------|--------|------|
| 🔵 Basic JP | 50x 下注額 | 250x 下注額 |
| 🟠 Major JP | 200x 下注額 | 1,000x 下注額 |
| 🔴 Grand JP | 1,000x 下注額 | 5,000x 下注額 |

- 貢獻率：每注 5%（Basic 3.0% / Major 1.5% / Grand 0.5%）
- JP 被打出後重置至初始值重新累積

### 觸發頻率設計

- Scatter 每格出現率：5%
- Free Game 平均頻率：122 轉/次
- 業界合理區間：80~200（落在合理中段）

## Free Game — 彩金穿門

### 流程

1. **Scatter × 3** 觸發 → 玩家選擇 Free Game
2. 盤面上出現帶彩金數字的特殊 symbol（顯示具體金額）
3. 穿門成功 → 直接獲得該 symbol 上顯示的彩金金額
4. 碰壁/未穿 → 不獲得該列彩金

> 設計邏輯：直觀的「看到多少贏多少」體驗，穿門成功的爽感更直接。

## Bonus Game — 大龍門挑戰系統

### 流程

1. **Scatter × 3** 觸發 → 玩家選擇 Bonus Game
2. 進入 **8 轉**累積模式
3. 每轉結果：穿門（牌值 × 1）+ 碰壁（牌值 × 3）+ 未穿（0 點）= 累積總點數 X
4. Bonus Game 結束 → 大龍門開啟，以 X 對照三層門

### JP 門對照

| 條件 | 結果 |
|------|------|
| 累積點數 < 60 | 保底小彩金 |
| 🔵 Basic JP 門：60 ~ 120（中心 90） | 命中中心 → Basic JP × 3 |
| 🟠 Major JP 門：130 ~ 200（中心 165） | 命中中心 → Major JP × 3 |
| 🔴 Grand JP 門：210 ~ 320（中心 265） | 命中中心 → Grand JP × 3 |
| 累積點數 > 320 | 保底中彩金 |

> 設計邏輯：累積點數越高挑戰越大的 JP 門。超出 Grand JP 不會落空，保底中彩金確保玩家不因表現太好而損失期待感。命中各層中心值可獲得 3 倍加乘。

## Main Game 結算顯示

- 每一欄（列）旁邊直接顯示該列的輸贏結果
- 穿門：顯示正數金額（如 +60）
- 碰壁：顯示負數金額（如 -20）
- 未穿：顯示 0 或不顯示
- 讓玩家一目了然每列的結果

## 彩金池動畫

- 上方 JP 三層數字持續跳動動畫（模擬彩金不斷增加的感覺）
- 每 10 秒實際增加一點金額到彩金池（視覺上持續累積）
- 增加時有微小的 pulse 動畫強調變化
