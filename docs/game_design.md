## Main Game — 射龍門 Slot

### 基本規則

- 3×3 轉軸，每格隨機出現 A~K（1~13）或 Scatter（龍符號）
- 每次 Spin 扣除 bet（bet 平均分配給三列）
- 每列獨立判定穿門/碰壁

### 射龍門判定規則

#### 正常門（左 ≠ 右）

| 條件 | 結果 | 效果 |
|------|------|------|
| 中欄落在左右界之間 | 穿門 ✓ | 依門寬賠率派彩 |
| 中欄 = 左或右界值 | 碰壁 | 不扣錢，扣 1 個 Scatter 累積燈 |
| 中欄超出範圍 | 未穿 | 無事發生 |

#### 同值門（左 = 右）

| 條件 | 結果 | 效果 |
|------|------|------|
| 中欄 = 同值 | 同值撞柱 | 不扣錢，扣 2 個 Scatter 累積燈 |
| 中欄 ≠ 同值 | 未穿 | 無事發生 |

#### 有 Scatter 的列

- 該列完全不做穿門/碰壁判定
- 只計算 Scatter 燈號（每個 Scatter +1）
- Scatter 格子沒有隱藏數值

### 穿門賠率對照表

| 門寬等級 | 左右差距 (gap) | 賠率 |
|---------|---------------|------|
| 極窄門 | 差 2（gap=1） | ×15 |
| 窄門 | 差 3~4（gap=2~3） | ×6 |
| 中門 | 差 5~8（gap=4~7） | ×3 |
| 寬門 | 差 9~11（gap=8~10） | ×1 |

> gap = max(左,右) - min(左,右) - 1

### 賠付計算

```
每列賠付 = (bet / 3) × 賠率
贏分 = 各列穿門賠付加總
```

### Scatter（龍符號）— 累積收集制

- 盤面每出現 1 個 Scatter → 累積燈號 +1
- 碰壁 → 燈號 -1
- 同值撞柱 → 燈號 -2
- 燈號最低為 0，不會變成負數
- **累積到 10 個 → 觸發選擇畫面**

### 觸發後：玩家二選一

- **Free Game**：連續 8 轉加強版 Slot
- **Bonus Game**：真實射龍門牌局

觸發後燈號歸零，重新收集。

## Free Game — 加強版 Slot（8 轉）

### 流程

1. 玩家選擇 Free Game
2. 連續 8 轉，玩法與 Main Game 相同（3×3 轉軸射龍門判定）
3. 不出現 Scatter（不會再觸發 FG/BG）
4. 中間門自帶額外獎金或倍率加成
5. 穿門成功 → 原本賠付 + 額外獎金/倍率
6. 8 轉結束，累積獎金歸入餘額

### 倍率加成設計

- 每轉的中間門會隨機附帶倍率（如 ×5、×10）
- 穿門成功時：基本賠付 × 該倍率 = 實際獲得
- 未穿門/碰壁：無額外獎勵

## Bonus Game — 真實射龍門牌局

### 流程

1. 玩家選擇 Bonus Game
2. 系統給予玩家 **bet × 50** 的籌碼
3. 進入射龍門牌局：
   - 發出左右兩張牌（玩家看到門寬）
   - 玩家決定這局要下注多少籌碼
   - 瞇牌揭曉中間那張
4. 穿門 → 從彩金池拿走「下注 × 賠率」的金額
5. 碰壁/未穿 → 扣掉下注籌碼
6. 玩家可選擇繼續玩或收手帶走已贏金額
7. 籌碼歸零 → Bonus 結束
8. 贏的金額 ≥ 池子剩餘 → 贏走整個彩金池，Bonus 結束

### 彩金池（累積制）

- Main Game 每次 spin 從 bet 中抽一部分進彩金池
- 貢獻比例：每注 5%（Basic 3% + Major 1.5% + Grand 0.5%）
- 依投注等級分三級：

| 投注等級 | 投注金額 | 對應池子 | 初始值 | 上限 |
|---------|---------|---------|--------|------|
| 小 | 15 / 30 | Basic | 50×bet | 250×bet |
| 中 | 60 / 150 | Major | 200×bet | 1000×bet |
| 大 | 300 | Grand | 1000×bet | 5000×bet |

- 玩家贏走池子後 → 池子重置回初始值重新累積
- 押小注只能玩小池，押大注才能挑戰大池

### 瞇牌設計

- 左右牌先發出，玩家看到門寬
- 中間牌面朝下，玩家可以「瞇牌」（慢慢揭曉）
- 製造射龍門最核心的緊張感

### Bonus Game 賠率

- 與 Main Game 相同：極窄×15 / 窄×6 / 中×3 / 寬×1
- 碰壁：扣掉下注籌碼
- 未穿：扣掉下注籌碼
