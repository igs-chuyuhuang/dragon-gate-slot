### 2026-06-15 — S23 Ultra symbol 不置中 bug 修正

**環節：** 程式
**AI 工具：** Kiro Agent
**做了什麼：** 修復特定手機解析度（如 S23 Ultra 3088×1440）下 symbol 垂直偏移問題。原因是 reel 高度除 3 產生小數，getCellH() 取整後 cell 高度與 reel 不完全匹配。修正方式：停輪後將 reel-strip 從固定 px height 切換為 CSS flex 佈局（height:100% + display:flex + flex-direction:column，每個 cell 設 flex:1），讓 cells 自動等分填滿。動畫期間仍用固定 px 計算滾動距離不受影響。另外微調最下列 symbol 的 margin-top（2→4px）。
**Before：** 某些解析度下 symbol 有 1~2px 垂直偏移，視覺上不置中。
**After：** 停輪後 cells 用 flex 自動等分，消除 sub-pixel rounding 問題。
**關鍵 prompt / 指令：** S23 Ultra symbol 不置中 bug 修正，停輪後用 CSS flex 取代固定 px
**人工修正：** 無
**耗時：** ~5 分鐘
