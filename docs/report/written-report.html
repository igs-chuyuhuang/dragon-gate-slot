一、製程創新

本專案採用全新的 AI Agent Fleet 開發模式：由一位人類操作者透過 Telegram 發出自然語言需求，由 Coordinator Agent 即時拆解為具體任務，分派給 10 個專業 Agent 平行執行。每個 Agent 獨立完成程式碼修改、commit 並 push，整個流程從需求到上線可在 5 分鐘內完成。

相較於傳統遊戲開發需要企劃、美術、程式、QA 等多個部門花費數月協調，AI Fleet 模式將溝通成本降至接近零——所有「跨部門協調」由 Coordinator 在毫秒級完成。開發者只需描述「想要什麼」，不需指定「怎麼做」，AI 自行決定實作細節。

這個模式的核心創新在於：將 AI 從「工具」提升為「團隊成員」。每個 Agent 有明確的職責邊界、持久的 context（記住過往修改），並能透過 MCP 協議互相通訊。這不是單純的「用 AI 寫程式」，而是「用 AI 組成一個完整的開發團隊」。

二、AI 技術與應用能力

本專案綜合運用多種 AI 技術：以 Claude Opus 為核心的程式生成引擎負責所有邏輯實作；AgEnD Fleet 系統管理多 Agent 協調；Pollinations AI 生成遊戲素材圖片；Python 腳本進行 RTP 機率模擬驗證；Google Apps Script 處理多人排行榜後端。

技術上最具挑戰的部分是 RTP（Return To Player）設計。Slot 遊戲的數學模型需要精確控制：太高玩家不會輸（遊戲無法營運），太低玩家感受差（留不住人）。我們透過 MISS_BIAS 機制（每列 20% 機率強制 miss）精準控制波動率，並用 Python 跑 10 萬次模擬驗證 RTP 落在 85-92% 區間。

另一個技術亮點是 JP（Jackpot）的 Symbol Pool 設計：根據玩家下注金額動態調整 pool 內容，高注玩家看到更多 JP 符號、中獎率更高，但數學上不會被低注高頻 exploit。這種「看起來公平但背後有精密控制」的設計完全由 AI 根據數學原理自行推導。

三、開發效率與成本優化

34 天內完成 750+ 次 commit，平均每天 22 次程式碼提交。這個速度在傳統開發中幾乎不可能達到——等同於一個 8 人團隊每人每天提交近 3 次有效修改。AI Fleet 模式消除了「等待回覆」「開會討論」「寫文件」等非生產性時間，將開發效率提升至傳統模式的 10-20 倍。

成本方面，傳統 Slot 遊戲開發需要 5-8 名專業人員（企劃、美術、前端、後端、QA）工作 3-6 個月，人力成本約 150-400 萬。AI Fleet 模式僅需 AI API 費用（月訂閱制），成本降低 95% 以上。

最令人印象深刻的是迭代速度：玩家回饋一個 Bug，從收到訊息到修正完 push 上線，通常不超過 5 分鐘。這讓「快速原型→測試→修正→再測試」的循環可以在一天內完成數十次，而傳統開發每次循環需要數天。

四、專案落地與遊戲品質

射龍門 Slot 是一款功能完整、可即時遊玩的 HTML5 遊戲。支援手機和桌面瀏覽器，無需安裝。遊戲包含完整的 Main Game（穿門機制）、Free Game（8 轉免費）、Bonus Game（12 局牌局）、Jackpot（三同中獎）四大系統，以及多人競賽排行榜。

技術品質方面：轉輪動畫流暢（CSS transition + overshoot 物理感）、特效豐富（BIG WIN 金幣雨、JP 紅金閃爍、贏線 glow）、手機自適應（純 % 定位 + clamp 字體）、效能優化（DOM 清理防記憶體洩漏）。數學模型經過 Python 模擬驗證 RTP 穩定。

多人競賽系統使用 Google Apps Script + Sheets 作為免伺服器後端，支援即時排行榜、組別平均分排名、倒計時競賽模式。整套系統從前端到後端完全由 AI agents 設計實作。
