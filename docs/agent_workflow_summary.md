## 工作方式

### 協調流程
1. 使用者在 Telegram 提出需求
2. **general**（協調者）分類任務、派給對應 agent
3. Agent 執行任務、commit + push
4. **general** 回報結果給使用者
5. 使用者反饋 → 迭代修正

### 品質保證
- **Visual QA**：Playwright 自動截圖 + AI 分析
- **語法檢查**：每次修改後 `node -c` 驗證
- **功能驗證**：Playwright 模擬 spin、確認無 JS error
- **使用者反饋迭代**：轉輪動畫經 12 次迭代才定案

### 知識管理
- `docs/dev_log/` — 每個 agent 的工作紀錄
- `docs/CURRENT_STATUS.md` — 即時狀態總覽
- `post_decision()` — 團隊決策記錄
- 每日 18:00 排程自動提醒更新 dev_log
